# SUMO-tools

Browsertools voor SUMO-microsimulatie, gepubliceerd via GitHub Pages. Handleidingen staan in `handleiding/` (gebouwd uit de [wiki](https://github.com/wimmichiels76/sumo-tools/wiki) met `python build_handleiding.py`).

| Tool | Bestand |
|---|---|
| netconvert Batch Generator | `netconvert_bat_generator.html` |
| SUMO Simulation Manager | `SUMO_Simulation_Manager.html` |
| SUMO VRI Manager | `SUMO_VRI_Manager.html` |
| SUMO TLS Editor | `sumo_tls_editor.html` |
| SUMO Network Link Manager | `sumo_link_manager.html` |
| SUMO Decal Generator | `sumo_decal_tool.html` |
| Masterplan Designer (geen SUMO-tool) | `masterplan_designer.html` |

Alles draait lokaal in de browser: bestanden worden gelezen en geschreven op de eigen computer, er wordt niets geüpload.
Gebruik Chrome of Edge voor directe mappentoegang (File System Access API). SUMO zelf moet lokaal geïnstalleerd zijn.
